# AI-Powered MERN Task Manager

An intelligent full-stack MERN task management application featuring AI-powered scheduling, Kanban boards, analytics dashboard, email notifications, and productivity tools.

# Live Demo

**Frontend:** https://task-manager-qlny.vercel.app

**Backend:** https://task-manager-backend-545d.onrender.com

# Features

## Authentication
- User Registration & Login
- JWT Authentication
- Secure Password Hashing
- Protected Routes

## Task Management
- Create, Update & Delete Tasks
- Task Priorities (High, Medium, Low)
- Due Dates
- Task Tags
- Task Status Tracking
- Task Dependencies

## AI Features
- AI Task Breakdown
- AI Smart Daily Planner
- Automatic Task Scheduling
- Productivity Suggestions

## Productivity Dashboard
- Interactive Analytics Dashboard
- Task Completion Statistics
- Productivity Insights
- Progress Tracking

## Kanban Board
- Drag & Drop Tasks
- Status-based Organization
- Visual Workflow Management

## Email Notifications
- Daily Schedule Email
- Upcoming Deadline Alerts
- Productivity Notifications
- Brevo Transactional Email Integration

## Workspace Management
- Create Workspaces
- Team Collaboration
- Workspace Members
